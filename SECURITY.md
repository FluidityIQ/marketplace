# Security Policy

This repository is a catalog manifest for FluidityIQ's Claude plugins. It does not run code or handle user data directly.

## Reporting a Vulnerability

For security issues in the **marketplace catalog** (this repo), contact:

- **Email:** security@fluidityiq.com

For security issues in a **specific plugin** (e.g., Patent Intelligence Plugin) or the **Patents MCP server**, please use that project's security policy:

- [Patent Intelligence Plugin — SECURITY.md](https://github.com/FluidityIQ/patent-intelligence-plugin/blob/main/SECURITY.md)

We will acknowledge your report and aim to respond within 5 business days.
